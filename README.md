# شکلات زرین

فروشگاه ساده شکلات، با دو بخش اصلی که از هم جدا شده‌اند: جعبه‌های کادویی و محصولات فله. تخته‌ای و مناسبتی هم کنار همین فهرست هستند.

ظاهر از کاتالوگ‌های خلوت شکلات الهام گرفته: نوار زیتونی، پس‌زمینه روشن، کارت محصول، و رنگ طلایی. نام فروشگاه و متن‌ها اصلی هستند.

## اجرا

دو ترمینال لازم است.

بک‌اند:

```powershell
$env:PATH = "$env:USERPROFILE\.dotnet;" + $env:PATH
$env:DOTNET_ROOT = "$env:USERPROFILE\.dotnet"
cd backend\Zarrin.Api
dotnet run
```

فرانت:

```powershell
cd frontend
npm install
npm run dev
```

سایت: http://localhost:3000  
API: http://localhost:5080  
Swagger در حالت توسعه: http://localhost:5080/swagger

اگر دستور `dotnet` پیدا نشد، SDK 8 در مسیر `%USERPROFILE%\.dotnet` نصب شده است. دو خط اول `PATH` را برای همان ترمینال تنظیم می‌کنند.

## چه چیزهایی دارد

- صفحه خانه، فهرست محصولات، جزئیات، سبد، ثبت سفارش، درباره و تماس
- فیلتر دسته و جستجوی نام
- سفارش در SQLite ذخیره می‌شود و موجودی کم می‌شود
- پیام تماس هم در همان پایگاه ذخیره می‌شود
- پرداخت آنلاین ندارد؛ هماهنگی تلفنی و پرداخت هنگام تحویل
- پنل مدیریت برای موجودی، سفارش‌ها و خریداران

## پنل مدیریت

نشانی: http://localhost:3000/admin

ورود پیش‌فرض، فقط برای کار محلی:

- نام کاربری: `admin`
- رمز: `Zarrin-1234`

قبل از اینکه سایت جایی منتشر شود، این رمز را در `backend/Zarrin.Api/appsettings.json` بخش `Admin` عوض کنید. سفارش تازه با وضعیت «ثبت شده» می‌ماند. از پنل می‌توان آن را تایید، ارسال، تحویل یا لغو کرد. لغو، موجودی را به انبار برمی‌گرداند.

خریدار حساب کاربری جدا ندارد. نام، موبایل و آدرسی که هنگام سفارش نوشته در فهرست خریداران دیده می‌شود.

## عوض کردن محصولات

فهرست در `backend/Zarrin.Api/Data/seed.json` است. بعد از تغییر، فایل `backend/Zarrin.Api/zarrin.db` را پاک کنید و بک‌اند را دوباره اجرا کنید تا داده‌ها از نو ساخته شوند.

اگر برای یک محصول عکس واقعی دارید، فایل را در `frontend/public` بگذارید و `imageUrl` را مثلاً `/images/ruby.jpg` کنید. تا وقتی عکس نباشد، یک تصویر ساده مخصوص همان دسته نشان داده می‌شود.
